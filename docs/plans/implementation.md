# Implementation sequence

1. Create workspaces, shared schemas and SQLite migration.
2. Implement auth, CRUD, imports, QR, SMTP durable worker and atomic scan engine.
3. Verify Phase 1 using integration tests before scanner work.
4. Implement admin UI and scanner PWA, pairing, IndexedDB queue and camera.
5. Add overrides, undo, exports and device management.
6. Run type checks, integration tests and production build; document deployment and limitations.

UI: pale slate #f4f7fa, deep navy #142b45, blue #2468ed, green #12724b, amber #a65d00 and red #b32638. System sans for controls, monospace for gate and device data. Quiet sidebar and compact operational tables. Scanner outcome occupies the whole central panel; no decorative charts.
